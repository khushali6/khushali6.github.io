Agentic AI · open source

Meadow

Agentic coding system

Turns a request into a planned, tested and reviewable coding workflow.

  • Each phase runs on its own git branch with guard checks and tests. Failures go back with the real error for up to 3 fixes, and only passing work merges.
  • A supervisor agent (Ollama, FreeLLMAPI or Claude) reviews failures, reports over Telegram and runs independent phases in parallel.
  • MCP tools sit behind approval gates and audit logs, with a CodeAtlas knowledge graph for cited answers.

Agentic AI · LangGraph

IntentRoute

Fuzzy intent to structured orders

Turns a vague request like "I feel bloated" into hard nutritional limits and a verified order.

  • A LangGraph state machine parses intent, enriches context, searches the catalog, maps constraints and verifies every limit.
  • Real data from TheMealDB and USDA FoodData Central via MCP tools, with structured Pydantic schemas.
  • If nothing matches, it broadens its keywords and retries on its own.

Talk to your database
