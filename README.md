# Khushali Pariyal — AI Engineer Portfolio

Premium static portfolio for Khushali Pariyal, AI Engineer and Agentic AI Engineer.

## Run locally

```bash
npm run dev
```

The site listens on `http://localhost:3000`.

## Deploy

Pushes to `main` deploy automatically to GitHub Pages through `.github/workflows/pages.yml`.

Expected URL: `https://khushali6.github.io/khushali-portfolio/`
