Agentic AI · open source

Meadow

A supervised coding agent that ships tested code

Turns a request into a spec and phased plan, then drives a coding engine phase by phase once a human approves.

  • Each phase runs on its own git branch with guard checks and tests. Failures go back with the real error for up to 3 fixes, and only passing work merges.
  • A supervisor agent (Ollama, FreeLLMAPI or Claude) reviews failures, reports over Telegram and runs independent phases in parallel.
  • MCP tools sit behind approval gates and audit logs, with a CodeAtlas knowledge graph for cited answers.

VLM · OCR · full-stack

SplitMate

Bill splitting that gets the numbers right

Reads receipt images and PDFs, pulls out the line items, and settles the group with the fewest payments.

  • OCR and vision-language models extract items, quantities, taxes and service charges into structured data, with a human-in-the-loop review step.
  • A deterministic math engine handles totals, proportional tax and rounding, so the LLM never does arithmetic. A debt-graph algorithm minimizes settlements.
  • Bring your own AI: configurable LLM endpoints, with Gemini supported.
